## Description of project
Talio is a task-management application perfect for any user who wants to simplify the way they organize their tasks and strive to stay on top of their to-do lists.
Our team has meticulously implemented the features, to provide you with a seamless experience.
We focused on a minimalist, modern design to maximize efficiency and clarity.
Whether you're a student, a professional, or just trying to keep your tasks organized, Talio has got you covered.

## How to run it
Firstly, install Gradle if you haven't already done so.
Then use the below commands to clone the repository:
```sh
git clone https://gitlab.ewi.tudelft.nl/cse1105/2022-2023/teams/oopp-team-01.git
cd https://gitlab.ewi.tudelft.nl/cse1105/2022-2023/teams/oopp-team-01.git
```
Once you navigated to the root of the project, you can now run it using the following commands:
- `./gradlew bootRun` (run the server)
- `./gradlew run` (run the client)

Alternatively, if you're using an IDE to open the project, you can run both the server and the client from there.

The client can run independently, without the server, but if no server is active then it is recommended to
run the server too in order to be able to actually use the features.
